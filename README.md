# STUDY LOOP ULTIMATE 2.0

Google Material風のシンプルなライトテーマに刷新した、学習管理PWAです。

## 2.0の改善点
- 白を基調にしたライトテーマ、文字・カード・ボタンのコントラストを整理
- メインメニューを「ホーム／計画／集中／復習／分析」の5項目に整理
- ノートと設定はヘッダーから開く構成に変更
- 集中タイマー専用画面を追加。計画から開始した場合もタイマー画面へ移動
- セクション見出しを日本語化して、画面内の意味を把握しやすく調整
- モバイルでは画面下部にナビゲーションを固定し、片手で移動しやすく変更
- 既存の学習記録・計画・復習・ノート・模試・バックアップ機能は維持

## GitHub Pagesへの更新
1. このZIPを展開します。
2. 展開した中身（index.html、app.js、styles.css、manifest.webmanifest、service-worker.js、iconsフォルダ等）を、既存リポジトリのルートへアップロードします。
3. 既存ファイルは上書きし、`icons` フォルダも残してください。
4. Commit changesで保存します。GitHub Pagesの設定が既に有効なら、通常はそのまま更新されます。
5. 公開URLを開き直します。古い画面が残る場合はChromeで再読み込みし、必要に応じてアプリを一度閉じて再度開いてください。

## データについて
- 保存キーは旧版と同じ `study_loop_ultimate_v1` を使うため、同じブラウザ・同じ公開URLの保存データを引き継ぐ想定です。
- 学習データは端末内のブラウザに保存されます。端末間同期はありません。
- 更新前に設定画面からJSONバックアップを保存することを推奨します。
- アプリの更新により、ホーム画面へ追加済みのPWAは一度再起動が必要な場合があります。

この版は静的HTML/CSS/JavaScriptで構成されています。ここではコード構文とファイル構成を確認していますが、Android実機やGitHub Pages上での公開動作は未検証です。
